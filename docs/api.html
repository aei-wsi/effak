API Documentation

Complete REST API reference for EFFAK

Base URL

http://localhost:5000/api

Authentication

Most endpoints require a valid JWT token. Include it in the Authorization header:

Authorization: Bearer <your_token_here>

Authentication Endpoints

POST /api/auth/register

Description: Register a new user

Access: Public

{
  "email": "user@example.com",
  "password": "securepassword123",
  "firstName": "John",
  "lastName": "Doe",
  "phone": "+1234567890"
}

POST /api/auth/login

Description: Login user

Access: Public

{
  "email": "user@example.com",
  "password": "securepassword123"
}

GET /api/auth/profile

Description: Get current user profile

Access: Private (requires token)

PUT /api/auth/profile

Description: Update user profile

Access: Private (requires token)

{
  "firstName": "Jane",
  "lastName": "Smith",
  "phone": "+1987654321"
}

POST /api/auth/change-password

Description: Change password

Access: Private (requires token)

{
  "currentPassword": "oldpassword",
  "newPassword": "newpassword123"
}

Household Endpoints

GET /api/households

Description: Get all households for current user

Access: Private (requires token)

POST /api/households

Description: Create new household

Access: Private (requires token)

{
  "name": "Smith Family"
}

GET /api/households/:householdId

Description: Get household by ID

Access: Private (requires token)

POST /api/households/:householdId/members

Description: Add member to household

Access: Private (Admin only)

{
  "email": "member@example.com",
  "role": "member",
  "relationship": "spouse"
}

Emergency Contact Endpoints

GET /api/households/:householdId/emergency-contacts

Description: Get all emergency contacts for household

Access: Private (requires token)

POST /api/households/:householdId/emergency-contacts

Description: Create emergency contact

Access: Private (Admin only)

{
  "firstName": "Jane",
  "lastName": "Smith",
  "email": "jane@example.com",
  "phone": "+1234567890",
  "relationship": "sister",
  "isPrimary": false,
  "notes": "Call in case of emergency"
}

POST /api/households/:householdId/emergency-contacts/:contactId/permissions

Description: Grant permission to emergency contact

Access: Private (Admin only)

{
  "categoryId": 1,
  "canView": true,
  "canDownload": false,
  "expiresInHours": 72
}

POST /api/households/:householdId/emergency-contacts/:contactId/send-access

Description: Send emergency access link

Access: Private (Admin only)

{
  "method": "email"  // or "sms"
}

Error Responses

All errors follow this format:

{
  "success": false,
  "message": "Error description",
  "errors": []  // Optional validation errors
}

HTTP Status Codes

  • 200 - Success
  • 201 - Created
  • 400 - Bad Request
  • 401 - Unauthorized
  • 403 - Forbidden
  • 404 - Not Found
  • 429 - Too Many Requests
  • 500 - Internal Server Error
